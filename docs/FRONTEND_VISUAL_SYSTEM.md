# 前端视觉规范

本规范记录工作台当前的视觉方向，供后续页面和组件沿用。功能性编辑区、画布节点和数据表格以可读性为先；氛围渐变只用于页面背景、标题区、卡片边缘和工具栏。

## 视觉层次

- **页面**：使用 `--canvas` 作为底色。主要页面可叠加透明的 `--ambient-warm` 与 `--ambient-cool` 径向渐变，保持大面积留白。
- **容器**：使用 `--panel`、`--border` 和 `--card-shadow`。标题区允许浅色线性渐变，内容区保持清晰的纯色或极低透明度底色。
- **强调**：主操作与选中状态使用 `--accent`、`--accent-soft` 和 `--cta-background`。不同任务卡可使用暖橙、青蓝、柔紫做视觉区分，但正文继续使用 `--text-strong`。
- **字体**：正文使用 `--font-ui`，页面标题与模块标题使用 `--font-display`。两套字体均包含中文系统字体回退，避免中文和拉丁字形割裂。

## 交互与可访问性

- 悬停反馈以边框、阴影和 1–4px 的位移为主；可拖拽画布节点不做位置变换，避免影响拖动。
- 交互动画使用约 180–280ms 的时长和 `--motion-ease`；系统开启减少动态效果时，现有全局规则关闭动画与过渡。
- 文本、状态提示和焦点标识不能只靠渐变表达。新组件应使用 `--text-strong`、`--text-muted`、`--focus-ring` 等主题变量，且验证浅色、深色与护眼模式。
- 护眼模式仅作用于工作区，需在 `WorkbenchAppearance.module.css` 内覆盖新增的颜色和阴影变量。

## 主要入口

基础变量与字体定义在 `src/styles/globals.css`；Ant Design 的对应字体和背景色定义在 `src/app/AppShell.tsx`。页面样式使用各自 CSS Module，避免向编辑器、第三方图表和弹窗扩散全局覆盖。
