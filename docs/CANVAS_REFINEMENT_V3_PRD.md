# 画布交互与视觉修订需求（V3）

本文件承接 [空间画布需求](SPATIAL_CANVAS_PRD.md) 与 [可视化需求](CANVAS_VISUAL_V2_PRD.md)，依据用户本轮反馈。与前两份文档冲突时，以本文件为准。

## 1. 工作区与远端布局兼容

- 画布继续位于工作区左侧资源栏，与文件、我的工具和远端新增的项目入口并列；文件编辑页和文件树均可打开对应关联画布。
- 远端项目页、项目标签、助手上下文和其他布局更新应保留；画布入口与之共存。
- 既有本地画布数据不得因与远端数据库迁移编号冲突而丢失。升级时要识别旧画布预览版的 33/34 号数据库，并补齐协作迁移后升级到统一版本。

## 2. 流程图箭头

- 图形编辑弹窗提供“箭头”和“直线”两种连接样式。新连线默认使用可见箭头；选择连线后可以切换样式。
- 保存并重新打开流程图后，节点、文字、连线样式和方向保持不变；画布上的缩略图须展示相同箭头或直线。
- 旧流程图未记录样式的连线按箭头展示；不要求输入 Mermaid。

## 3. 笔记富文本

- 点击笔记正文即可编辑。格式工具栏位于正文上方，提供加粗、斜体、下划线、删除线、无序/编号列表、字号、高亮、字色和便签底色；选中文字后点击格式按钮直接生效，支持常见键盘快捷键。
- 文字局部格式与便签底色保存到画布，重启后可继续编辑。旧纯文本笔记及 `==高亮==` 语法继续可读，进入编辑时平滑转换。
- 粘贴外部内容时按纯文本插入；保存和预览富文本时只允许安全的文字排版标签、颜色和字号，不执行脚本、外部图片或嵌入内容。
- 工具栏在窄组件中自动换行，文字与控件在浅色、深色主题下均清晰。

## 4. AI 摘要视觉

- 摘要以具有层级的研究札记样式展示：清晰的标题/分节、强调段落、列表、引用、来源标识和柔和的双色背景。
- 保持内容本身的可读性，样式在深色、浅色主题下保持对比度；继续用现有安全 Markdown 渲染器处理 AI 文本及 `document_patch` 提取后的正文。

## 5. 验收

1. 在图形编辑器创建箭头，保存并重开后方向与样式仍在；选中改为直线后缩略图不再显示箭头。
2. 创建笔记、选择文字使用加粗和高亮，保存、刷新后格式仍在；旧笔记与恶意粘贴内容可安全读取。
3. AI 摘要的标题、列表、引用和来源展示正确，界面不存在白底白字。
4. 远端项目工作区和画布工作区均可打开；本地旧画布数据库与新安装数据库均可升级。
5. 类型检查、代码检查、自动化交互测试及桌面构建通过，再推送到远端。
