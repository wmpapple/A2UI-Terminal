# UI 性能与交互优化验证

日期：2026-09-18；实施账本 LOG-0180。基于前两轮视觉与护眼模式继续修改，未重建桌面安装包。

## 实现

- 聊天输入识别输入法组合状态，保留 Enter 发送、Shift+Enter 换行，支持 Ctrl/Cmd+Enter；生成中不重复提交。提示词按钮只填入内容，发送复用 Context Manifest 确认。
- 聊天草稿以工作区与会话标识隔离，保存在 Zustand 内存，跨页面和会话切换保留；发送时清除当前草稿，删除工作区只清除该工作区草稿。退出或刷新后不保留，不新增 localStorage、IndexedDB 或文件中的正文副本。
- 阅读历史时暂停自动跟随并固定当前消息窗口；“回到最新消息”恢复跟随。每批最多挂载 60 条消息，可以双向翻阅；重试仍使用完整会话中的原始消息索引。
- 成果列表每页 40 条，提供上一页、下一页、当前范围与总数；翻页后聚焦标题。前端仍读取现有摘要集合，本轮限制的是 DOM 数量，没有改造后端分页或承诺固定内存上限。
- 文件编辑器和侧栏改用细粒度状态订阅；已完成的助手 Markdown 使用 memo，避免输入等无关变化重复渲染正文。
- 设置、模板、成果、编辑器、助手、专业侧栏及新建弹窗按需加载；加载时显示骨架屏，失败可局部重试，不刷新整个应用。
- Ctrl/Cmd+K 或导航右侧搜索按钮打开命令面板；方向键选择、Enter 执行、Esc 关闭。面板复用本地授权搜索，可以导航或新建成果。已有弹窗打开时快捷键不抢占焦点；Markdown 预览支持 Esc 退出。
- 主按钮使用克制的蓝紫渐变；护眼模式覆盖为柔和纯色。保留减少动态效果支持，不引入持续光晕动画、CDN、音效或新的依赖。

## 自动验证与观察

- 最终 typecheck、lint、format、生产构建与 git diff --check 均通过。
- 最终完整单测：52 文件 / 232 项通过，包括工作区草稿隔离及删除清理用例。
- 21 个 Playwright 场景：全量首轮 17 通过、2 次浏览器崩溃后重试通过、2 失败。失败分别为旧分页文案断言及 Chromium 页面崩溃；更新断言后，两项通过 `--last-failed --workers=1 --retries=1` 首试复验。不是单轮无波动全绿。
- 新增浏览器场景验证命令面板键盘导航、授权搜索、新建成果、草稿跨页面保留、会话隔离、提示词不自动发送、快捷发送仍需确认。
- 消息列表单测以 2000 条消息验证 DOM 有界、翻阅和重试索引；阅读中到达新消息不会改变滚动位置或挤掉当前阅读窗口。
- 已检查命令面板与聊天工作台截图；既有 900px 中英文布局和护眼模式场景通过。
- 本地 Web Mock 一次复验：首页可交互 273.9ms、请求反馈 8.7ms、成果打开 335.8ms，均在现有预算内。这些是开发服务器单次样本，不是桌面冷启动 FCP、滚动 FPS 或性能分位数。
- 入口 JS 由上一轮约 1389.71kB（gzip 448.51kB）拆分为约 317.17kB（gzip 100.87kB），同时生成共享依赖和功能 chunk。入口体积不等于首屏总传输体积，不能把该比例作为加载时间或内存降幅。
- 现有 Ant Design 部分 API 弃用/静态 message 主题提示仍在；本轮没有扩大到全组件 API 升级。

## 桌面人工复验

1. 中文输入法选词回车不发送；Ctrl+Enter 正常进入确认流程，Shift+Enter 换行。
2. 在两个会话、两个工作区输入不同草稿，往返切换及进入设置后检查隔离与保留。
3. AI 生成时上翻阅读，确认不会被拖回底部；点击“回到最新消息”恢复跟随。
4. 使用 Ctrl+K 搜索、方向键选择、Enter 打开成果或新建，Esc 关闭；切换语言、专业模式与护眼模式复验布局。
5. 检查成果翻页、长对话翻阅、Markdown 预览 Esc 退出，以及模块首次加载占位。
