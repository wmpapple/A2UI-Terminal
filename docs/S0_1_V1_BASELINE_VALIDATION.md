### 4.2 功能归属

#### Provider 可靠性与凭据

- 连接、响应头、流空闲和总流时长采用分阶段超时。
- 取消覆盖连接、响应等待和流读取；部分响应以 `stopped` 保留。
- HTTP/网络/超时/协议/限流映射为稳定错误码与可重试元数据。
- 临时 API Key 使用清零包装；配置失败恢复旧凭据和旧设置。
- 远程 Endpoint 强制 HTTPS，本地回环允许 HTTP；URL 禁止内嵌凭据、查询和片段。

#### 真实文件版本历史

- schema v7 为 `document_versions` 增加 `source` 和 `summary`。
- 普通自动保存、Patch、恢复共享版本链；恢复创建新版本，不删除历史。
- 版本写入失败时回滚磁盘并保留恢复草稿。
- 前端增加版本列表、正文按需预览和安全恢复入口。

#### SQLite 与崩溃恢复

- schema v8 为草稿增加正文 SHA-256 和恢复查询索引。

- 迁移故障注入、损坏数据库、v7 回填和跨重启恢复均有 Rust 测试。
