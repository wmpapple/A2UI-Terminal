# M1-A 产品功能验收

本清单仅检查产品功能和体验。自动测试、迁移、协议、权限及构建由代理负责；工程状态见 [实施记录](M1A_EXECUTION.md)。当前待用户产品验收。

启动 [M1-A 整合版](../../logs/m1a-integrated-review/a2ui-terminal.exe)，进入主导航“资料库”。如果旧程序仍开着，先正常退出后再启动此版本；不需要手工运行命令或检查数据库。

已准备可直接导入的虚构样本：[Markdown](samples/M1A_Knowledge_Sample.md)、[CSV](samples/M1A_Knowledge_Sample.csv)。可搜索“星河”或“420”。

- 打开“资料库 → 全部资料”，导入一份 TXT/MD；取消时不出现资料，确认后可预览正文。
- 改名称、添加标签，用正文关键词或标签查到资料；重启后仍保留。
- 再导入相同内容，已有资料被复用，没有重复列表项。
- 试一份带文本层的 PDF、DOCX 或 CSV/XLSX；正文可读。扫描 PDF 会提示不支持 OCR。
- 移动原文件后，资料库副本仍可预览。删除资料库条目后，原文件仍存在。
- 在首页搜索到资料并打开预览；切换工作区后仍可找到同一份资料。
- 在写作助手的发送前确认中选择个人资料，发送清单显示该资料；不选择时不包含它。下一次发送需要重新选择个人资料。
- 检查熟悉的成果编辑、查看修改和导出仍正常。

本轮整合重点：

- “资料库”包含“全部资料”和“资料包”；设置里的管理按钮跳转到同一资料包页面。
- 在“资料包”中选择工作区（已有工作区时会显示名称），从个人资料中选一项并创建资料包，也可混合加入工作区资料，总计最多 20 项。
- 在写作助手发送前选择该资料包，生成发送清单后能看到包内的具体资料；仍需确认后才发送。
- 删除资料包后，返回“全部资料”，原资料仍可打开。
- 修改个人资料名称后，资料包显示新名称；删除个人资料后，相应引用移除，空包移除。已有工作区资料包仍可使用。

范围说明：个人资料跨工作区复用，资料包本轮继续按工作区保存，页面标明所属工作区。没有把旧工作区授权改成全局授权。

无需逐项做全量回归。反馈尝试过的功能、预期和实际表现即可；没有试过的项目可保留未测。完成后仍须你明确允许，才会进入 M1-B。
