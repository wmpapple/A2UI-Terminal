# M5-B 产品验收

验证程序：`logs/m5b-hybrid-search-review/a2ui-terminal.exe`。也可使用 `npm run desktop:dev`。请使用自己的向量模型服务；程序没有内置模型，也不会自动下载或启用云端服务。工程评测用的临时本地模型由代理单独运行，不随验证程序常驻。

1. 先在设置中配置本机服务或云端 BYOK 服务。该服务需支持向量接口；聊天模型名称通常不能直接作为向量模型使用。
2. 导入几份主题不同的资料，在首页搜索正文关键词，确认原来的关键词搜索正常。输入一个意思相近、用词不同的搜索句，点击“语义搜索”。
3. 第一次选择处理服务、向量模型名称、版本标记和该模型的实际维度。点击“规划发送范围”，核对服务地址、搜索词、资料列表和新片段数量。取消某份资料并“更新发送清单”，确认其不再出现在本次范围内。
4. 点击“确认并搜索”，观察进度、结果和摘要；再次搜索时，未变化的已处理资料应显示“需发送 0 个新片段”，搜索词仍会发送。点击提示框关闭按钮，确认可正常关闭。
5. 删除一份资料，重新搜索，确认不再返回它；退出重开程序，确认向量配置和未变化资料的缓存可复用。
6. 处理中点击“停止”或关闭窗口，确认返回可操作状态。使用暂时不可连接的服务地址再尝试，确认说明失败原因并保留关键词搜索结果。
7. 从搜索结果打开成果或选中资料进入工作台，确认原有写作、发送清单和审阅不受影响。

模型质量、权限、数据迁移、清理、自动测试和构建由代理验证，不需要你操作数据库或运行工程测试。反馈 M5-B 产品验收是否通过即可；通过并获得下一阶段授权前，不开始 M6。
