# M5-A 产品验收

验证程序：`logs/m5a-persistent-search-review/a2ui-terminal.exe`。也可使用 `npm run desktop:dev`。首次搜索新增的大批资料时会显示加载，后续搜索复用本机索引。

1. 导入几份含有容易区分关键词的中文或英文资料，在首页“搜索本地内容”中搜索正文关键词，确认标题、摘要和打开入口正确。
2. 完全退出程序再打开，搜索同一关键词，确认仍能找到资料。
3. 在资料库修改资料标题或标签，返回首页搜索新标题/标签，确认结果更新；删除一份资料后，确认其独有关键词不再命中该资料。
4. 在工作区授权一个文本文件，搜索其中的独有关键词；在外部编辑器保存新内容后再次搜索，确认能找到新词。撤销该文件授权后，确认该来源消失。若同内容另存为成果或个人资料，其独立副本仍可以命中。
5. 点击首页“修复搜索”，再次搜索，确认资料仍可找到，已有成果正文和历史记录保留。
6. 从搜索结果打开成果或选择资料继续写作，确认原有生成、授权清单和审阅体验正常。

性能、迁移、权限、数据清理、并发与自动回归由代理验证，不需要用户操作数据库或制作大规模样本。完成后请反馈 M5-A 是否通过；在明确通过前，不开始 M5-B。
