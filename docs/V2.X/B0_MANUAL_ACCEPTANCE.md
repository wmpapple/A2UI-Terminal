# B0 产品整体验收

本阶段验证“资料 → 偏好 → 生成 → 原地修改 → 引用 → 保存与导出”的联动。技术测试、权限、构建和数据兼容检查由代理负责；你只需检查功能、体验和输出结果。

验证程序：`D:\A2UI\A2UI-Terminal\logs\b0-product-beta-review\a2ui-terminal.exe`。关闭旧窗口后打开，也可使用 `npm run desktop:dev`。

1. **完整写作任务**：导入一份自己的测试资料，保存写作偏好，新建成果，选择资料并生成一篇短文。检查偏好、关键数字、否定关系与引用原文是否正确；接受前不应改动正文。
2. **原地修改与恢复**：选一段润色，接受后检查选区外内容；检查原有引用变为待核验，撤销或恢复历史版本后来源仍可查。另存副本并导出 Word/PDF，检查正文和来源列表。
3. **写作中途切换**：编辑、发送后切换首页，再回工作台；写作内容应保留，已发送输入应清空。关闭程序后重开成果，已保存正文和来源应保留。
4. **本地模型与异常恢复**：如已使用本地模型，继续检查无 Key 的生成流程；停止生成、服务不可用或修改要求后，应能重新操作，不能自动覆盖成果或静默切换云端。仅使用 BYOK 时按自己的已配置服务验收。
5. **正常使用几分钟**：在首页、资料库、成果、设置间切换，检查打开速度、保存状态、提示关闭和界面是否异常。自动更新未配置时不应打断写作。

“来源已核验”只说明来源关系、授权和版本一致；仍需检查原文是否支持结论。本轮固定返回文本的测试服务证明工程链路，不代表所有 BYOK 模型的输出质量。真实模型效果按你使用的模型检查，不要求运行技术脚本。

完成后回复“B0 验收通过，开始下一阶段”，再进入 M5。本轮未开始 M5，未执行正式发布、签名安装或用户数据迁移之外的发布操作。
