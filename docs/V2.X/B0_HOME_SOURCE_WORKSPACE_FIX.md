# B0 验收修复：首页资料独立归属

首页的选择资料、浏览器拖放回退和原生拖放入口此前都传入当前工作区 ID。后端因此把外部文件授权关联到当前工作区，但并没有将文件移动到工作区目录。

现在这三个首页入口不指定工作区，复用后端已有的“独立文件”归属逻辑。确认添加后，工作台切换到返回的独立文件工作区。首页中英文说明同步解释归属及原文件不会移动。工作台内主动向当前工作区添加文件的入口保持原有行为。

既有关联保留，不自动迁移或撤销，避免影响已有引用、对话和编辑。

验证：16 项首页入口与导入状态测试通过，新增已选择目录工作区时三个入口仍不绑定其 ID 的回归；TypeScript 和相关文件 ESLint 检查通过。

人工检查：先选择一个目录工作区，再到首页添加该目录之外的资料；确认后进入工作台，应显示“独立文件”，切回原目录工作区不应出现本次新资料。

本次仍属于 B0 验收修复，未进入下一阶段。

## 独立文件名称显示

最近工作区列表与当前工作区名称现在根据已授权文件显示：单文件显示完整文件名，多文件显示“首个文件名 等 N 个文件”。历史独立文件记录读取时也适用，无需迁移数据库；目录工作区及“我的成果”保留原名。下拉选项保留完整名称提示。确认导入后立即返回更新后的名称。

本次验证：后端单元测试 218 项通过、1 项忽略；侧栏测试 7 项通过；TypeScript 检查通过。
