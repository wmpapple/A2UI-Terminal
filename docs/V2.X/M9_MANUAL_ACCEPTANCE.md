# M9 场景化工具人工验收

M9 当前版本已完成工程验证，等待产品验收，不进入 M10。用户只需检查功能和体验。

程序：`logs/m9-workbench-baseline-review/a2ui-terminal.exe`，也可使用 `npm run desktop:dev`。这是未签名的本机验收构建。

## 模板页定型

1. 页首说明应明确：从模板创建工具，工具自动保存到“我的工具”，成果需要用户主动保存。
2. 顶部只出现一张紧凑的推荐卡；当前推荐内容允许由推荐策略切换。下面仍是五张内置模板卡，不出现搜索、筛选和分类侧栏。
3. 每张内置卡有不同图标、淡橙标题区和最多两个适用范围标签；普通卡在宽屏保持三列等高布局，操作区对齐贴底。
4. 五张卡的操作统一为“使用模板／自定义 →”。“使用模板”直接创建并进入工作台；“自定义 →”打开名称、字段和关联设置，确认按钮为“创建工具”。
5. “我的模板”没有内容时，应显示保存来源说明和“前往我的工具”；点击后进入「工作台 → 我的工具」。
6. 保存一个个人模板后，卡片显示“我的模板”、更新时间及“基于：原内置模板”。主操作仍为“使用模板”，更多菜单提供删除。复用后填写值和关联为空。

## 本轮重点

1. 打开「工作台 → 我的工具」。工具顶部不应出现“保存填写”和重复的“我的成果”按钮，只显示“正在保存／已自动保存／自动保存失败”。
2. 左侧每个工具固定显示两行身份：工具名，以及“关联对象／未关联 · 成果 Rev N／成果待更新 · 时间”。选中项使用浅橙背景和左侧橙色指示条，不出现整块深橙。
3. “新建工具”下方提供搜索，以及同一行的“全部／已关联／未关联／已有成果”筛选；四类都显示数量，搜索标题、关联对象或成果名称都能缩小列表。
4. 删除按钮不常驻。悬停工具行后显示 `...`，菜单包含重命名、关联对象、保存为个人模板和删除工具；删除仍需二次确认。
5. 打开独立工具时，标题下显示“未关联对象 · 可独立使用”；关联正常时显示“关联：对象名 · 正常”，目标变化后显示“关联：对象名 · 已更新”和重新核对入口。
6. 自动保存状态以 12px 弱提示显示“已自动保存 · 时间”，不与“保存为成果／更新成果”争夺主操作层级。
7. 表单分区维持平面结构，标题为 16px，上方 24px 留白并用浅色分隔线区分，不增加卡片嵌套。
8. 表单按“基本信息”和各模板业务段落分组，组间有分隔线和留白；已有工具也应用相同分组，不影响原填写或自动保存。
9. 首次点击“保存为成果”后，按钮变为“已同步”，并显示“已关联成果：名称 · Rev 1”和查看成果入口。继续修改并等待自动保存后，应显示“● 工具有更新，成果未同步”和“更新成果”。
10. 点击“更新成果”后仍关联同一个成果，修订号增加，按钮恢复“已同步”。自动保存工具本身不会偷偷更新成果。
11. 右侧打开 `...`，应看到保存为个人模板、重命名、更换关联对象、重置工具和删除工具。重命名后左侧名称立即更新；如果已有成果，应提示成果未同步。
12. 删除一个工具并确认后，该工具从列表消失。若它已经手动保存过成果，成果仍应保留。
13. 关联文档或成果后，简单模式会自动检测状态，不显示普通“刷新状态”按钮。对象变化、未保存或不可用时才出现警告和重新核对入口；专业模式可看到手动刷新。

## 完整回归

1. 模板页只负责推荐、内置模板和我的模板，没有蓝色说明框或“我的工具”实例列表。五个内置卡片都有“使用模板”和“自定义”，并用轻量标签显示用途、可独立和可关联。
2. “使用模板”直接创建独立工具并打开；“自定义”可改名称、字段和可选关联。所有五类工具都能不绑定文件使用。
3. 工具状态跨「文件／我的工具」、首页往返和程序重启保留；工具保存、导出不覆盖文件侧未保存输入。
4. 关联对象可选择文档、成果、Task、Workspace，也可解除关联。解除或更换后填写内容保留，核对状态重置。
5. 展开“关联详情与核对依据”可看到可读的保存时间和方式；内部修订标识位于更深的详情中。关联对象变化后旧核对不会继续显示为当前有效。
6. 保存为个人模板后，新实例不继承当前填写、绑定、核对或成果关系。JSON／PDF 导出包含填写、未勾选项与当时的关联状态。

范围：发布检查最多 20 项，采访／审核／任务最多 5 项，收集最多 15 项；项目名最多 24 字、字段最多 1000 字。文档绑定支持 Markdown／纯文本；PDF/DOCX 精确定位、旅行专用 Result 和外部 Action 不属于 M9。
