2026-09-28：用户确认 M5-A 验收通过，授权开始 M5-B。沿用 React / TypeScript / Tauri / Rust / SQLite；保留工作树中已验收的 M5-A 改动。M5-B 完成工程验证后等待产品验收，不进入 M6。

## 本阶段行为

首页及快捷命令中的“搜索本地内容”保留自动关键词搜索，新增手动“语义搜索”。第一次选择已配置的服务、专用向量模型、模型版本标记和维度；本机服务优先排列，支持本地服务和云端 BYOK，没有内置付费服务。聊天模型和向量模型分别选择，API Key 沿用系统凭据存储。

规划阶段不读取密钥、不请求向量服务。确认窗口展示实际服务地址、模型、搜索词、资料标题、新片段数及字符数，可以取消勾选来源并更新清单。确认后才发送所需正文片段和搜索词；缓存片段不重复发送。云端费用由服务商收取，本程序不承诺准确金额；发送前提供可核对的数据量。每次语义搜索均单独确认，既有写作发送清单的复用规则保持。

按每批最多 8 个片段建立向量，进度可见、可停止。SQLite 保存模型/服务标识、版本、维度、正文 SHA-256 和向量。重启或中断后复用已完成的批次，需要用户再次发起并确认，不自动恢复网络请求。修改模型权重后应更新版本标记；程序无法验证远端模型的实际权重。

词法 BM25 和余弦相似度分别选取候选，按来源去重后使用 RRF（k=60，等权，各最多 50 个来源）融合；范围过滤在候选截断前执行。服务连接失败、超时、限流、无效响应或维度不符时，返回重新核对过的关键词结果并显示可关闭的原因提示。

## 工程边界

- IPC 沿 controller → gateway → commands → application → repository。新增四个明确授权的命令，没有开放任意网络请求或任意文件读取命令。
- 新增 schema 25，不修改历史迁移；向量通过外键依附持久片段。修改/删除来源、撤销授权、修复搜索、清空本地数据覆盖派生向量。模型/服务变化隔离缓存；修复搜索和清空本地数据可用于主动清理。
- 计划绑定不可变模型配置、来源片段及 hash；15 分钟有效期，最多 8 个待处理计划。发送前、响应后再次验证授权和正文；来源删除或配置改变的旧结果不能写回。取消和页面卸载会废弃计划并忽略迟到响应。
- HTTP 限制：单批 8 项、连接 5 秒、请求总计 30 秒、响应 8 MiB，禁止重定向。本机端点绕过代理；云端沿用现有 HTTPS/代理校验。无效、零、非有限值或维度不匹配的向量不入缓存。
- 本次接入首页搜索。资料库列表、AI 写作上下文选择与引用映射继续各自现有流程；搜索命中不等于引用已核验，不会自动把全库发送给写作模型。
- 当前采用精确余弦扫描，每次最多 10000 个片段；没有实现 ANN、复杂 rerank、后台自动全库向量化。超过上限提示错误，可使用较小的授权工作区范围或继续关键词搜索。尚未宣称 10000 个向量的性能达标，M5-A 的词法性能不能替代该测量。
- 用户选择的模型需提供兼容的 `/embeddings` 接口、float 向量及 index。输入长度上限取决于模型；超长文本的截断/质量需要按实际模型验证。

## 验证方法

`src-tauri/tests/semantic_search.rs` 的流程测试使用可控适配器验证授权、缓存、重启、配置失效、删除期间写入拒绝、选中范围与清空数据。HTTP 测试使用真实回环连接验证响应排序、数量、维度、重定向及异常状态；这些测试不充当模型质量证据。

真实模型评测使用 [Xenova/paraphrase-multilingual-MiniLM-L12-v2](https://huggingface.co/Xenova/paraphrase-multilingual-MiniLM-L12-v2)，固定 revision `2c4055b12046f11709e9df2c122e59ffbdc2f900`、384 维、q8 ONNX、本机 CPU。运行时为 `@huggingface/transformers@3.8.1`，仅安装在忽略的 `logs/m5b-model`，不加入产品依赖或安装包。官方模型下载连接超时后使用公开镜像下载同一固定 revision；ONNX SHA-256 记录在交付快照，推理期间关闭远程模型加载。

`evals/retrieval/cases.json` 在评测前固定 12 份合成资料和 24 条中英文查询，含 12 条直接匹配和 12 条改述，每条有一个标注相关来源。通过真实 HTTP 适配器和产品完整混合排名路径，与 M5-A 词法排名逐条对比。门槛为 MRR@5 ≥ 0.75 且比词法提升超过 0.05。该小规模固定集只用于回归，不代表所有模型、文档类型或真实客户资料的效果保证。

复现真实模型评测（PowerShell，首次下载需要网络；只向回环地址发送合成 fixture）：

```powershell
npm install --prefix logs/m5b-model --no-audit --no-fund @huggingface/transformers@3.8.1
npm run eval:retrieval:server
# 另一个终端，保持评测服务运行
$env:M5B_EMBEDDING_ENDPOINT=(Get-Content -Raw logs/m5b-model/ready.json | ConvertFrom-Json).endpoint
npm run eval:retrieval
npm run test:semantic:desktop
# 完成后在服务终端按 Ctrl+C 释放模型
```

桌面脚本仅对全新临时数据目录操作，禁用真实凭据，验证实际交付 exe 的确认前零请求、真实本地模型、缓存复用、断网回退，以及既有生成/审阅/导航/保存/重载链路。原始日志为 `logs/m5b-*`；最终结果及程序 hash 见 `M5B_DELIVERY_SNAPSHOT.json`。技术验证由代理完成，用户只需 [产品验收](M5B_MANUAL_ACCEPTANCE.md)。
