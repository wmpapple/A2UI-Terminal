# B0 验收修复：工作区文件不再自动进入成果

问题：`read_workspace_file` 在读取后自动登记成果，导致仅查看文件也出现在“我的成果”。

修复：读取命令只读取工作区文件。普通文件的打开、保存与重开不会创建成果记录；主动创建成果的流程继续使用独立入口。没有新增“保存为成果”按钮，也没有修改已有成果的保存方式。

兼容：保留之前登记的成果记录及原文件，避免影响用户已经进行的编辑、引用和版本历史。本次不自动清理历史记录。

工程验证：新增工作区与成果边界回归，覆盖读取、重复打开、编辑保存、数据库重开、已有文件成果兼容，并检查 IPC 入口不再自动登记。与引用和 B0 整链测试一起执行，共 13 项通过。

格式检查与桌面构建通过。验证程序：`logs/workspace-result-fix-review/a2ui-terminal.exe`。本次真实桌面自动回归未完成：WebView 调试端口连接被拒绝，重试以及直接使用构建目录程序仍失败，不能将此前 B0 的桌面验证结果视为此二进制的验证结果。失败记录位于 `logs/workspace-result-fix-desktop/report.json` 与 `logs/workspace-result-fix-desktop-target/report.json`。

人工检查：打开一个此前没有打开过的工作区文本文件，查看、编辑保存后进入“我的成果”，不应出现该文件；原有成果仍可打开和保存。
