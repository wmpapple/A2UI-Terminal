# M8 编辑器与文档模型决策

状态：本阶段实施决策。2026-09-29，用户已接受 M7 并授权 M8；不包含 M9。

## 存储与适配边界

保留 Markdown 为文档正文和历史记录的持久源，增加平台无关的 `StructuredDocument`：Heading、Paragraph、TextRun、List、Table、Quote、Image、PageBreak，以及保留未知语法的 Unsupported 节点。每个结构块带独立 UUID。节点的 source 是 Markdown adapter 的原始切片，含块间空白；非编辑块不因转换被整体重新排版。

SQLite migration 0028 新增 document_structures，按文档目标和正文哈希保存结构快照；关联成果/工作区删除，撤销单独文件授权时清理，清空本地数据时清理。每个目标最多保留 100 份结构缓存，原有正文历史不受此上限影响。缓存淘汰后重新解析，因此不承诺永久跨所有旧版本保持同一段落 ID。源文件外部修改时先匹配相同块，再匹配剩余同位置块；外部同时重写、重排的歧义无法可靠推断身份。结构化操作自身保留被修改/移动块 ID。

## 可替换编辑器

首版复用 React/Ant Design，并采用浏览器原生可编辑区域处理简单段落及粗斜体，表格以单元格输入处理。`editorAdapter.ts` 负责 DOM 到有限 Markdown 标记转换，不把 DOM/编辑器对象保存到数据库。粘贴只接收纯文字；有链接、代码等复杂内联语法的块使用源码编辑，保留原语法。列表、复杂块也可编辑源码。未知块可查看、移动、删除，原文保持可恢复。

此阶段不增加大型编辑器依赖。以后替换为其他富文本编辑器只需替换 adapter；DocumentTarget、AST、Patch V2、Review、Revision 不依赖组件库。当前交互是独立结构化编辑面板，原有 Markdown 编辑与 AI 选区编辑继续可用。

## 写入与导入

Patch V2 接受 replace_text、replace_block、insert_block、delete_block、move_block、change_heading、insert_table、update_cell；insert_block 覆盖段落、列表、图片和分页。Rust 根据当前授权正文解析目标，不接受客户端 AST 作为事实。验证目标、哈希、版本、无未保存草稿后生成统一 Review；接受时再次检查绑定，再沿既有写入/Revision 流程执行。结构化提案为一个原子审阅块，整组接受或放弃，不作有依赖操作的部分应用。撤销与历史恢复复用现有功能。

原有 AI 生成和行内修改仍生成 Markdown 审阅候选；本阶段不强迫用户模型支持新的结构化工具调用。下次打开结构化面板时按新正文更新结构。

Word/Markdown 导入通过系统选择器读取用户选定的文件，只生成替换当前 Markdown 正文的审阅副本，确认后才写入。没有从前端传任意路径读取的接口。PDF 继续只读。DOCX 解析只读 ZIP 内条目，不提取路径、不访问外部关系；限制压缩文件、展开大小、条目数、图片尺寸及正文大小。合并/嵌套表格明确拒绝转换。结构化预览与 Word 转换不加载图片网址；原有普通 Markdown 阅读器仍遵循其既有图片呈现规则。

## 格式能力矩阵

| 内容                                       | Markdown / 结构编辑                 | DOCX 导入与导出                                      | PDF 导出                 |
| ------------------------------------------ | ----------------------------------- | ---------------------------------------------------- | ------------------------ |
| 标题、段落                                 | 支持，标题 1–6                      | 基础结构；识别 Heading1–6                            | 支持标题层次与正文       |
| 粗体、斜体                                 | 支持                                | 显式格式保留；不解析复杂样式继承                     | 粗体基础呈现；斜体不保真 |
| 列表                                       | 单层编辑；复杂语法保留源码          | 导出可见序号/项目符号；外部 Word 编号简化为项目符号  | 文本列表                 |
| 简单表格                                   | 编辑单元格、源码调整行列            | 矩形表格；不支持合并/嵌套                            | 文本行，非网格保真       |
| 图片                                       | 系统选择 PNG，预览内嵌图片          | 内嵌 PNG，≤1 MiB、宽高≤4096；外部/其他格式以说明代替 | 图片说明                 |
| 分页                                       | `<!-- pagebreak -->` 标记及预览分隔 | 实际分页                                             | 实际分页                 |
| 链接、代码等额外语法                       | 原文保留，使用源码编辑              | 有限文本表示，不承诺语义往返                         | 既有 Markdown PDF 能力   |
| 页眉页脚、脚注、修订、浮动排版、自定义样式 | 不支持编辑模型                      | 不保留；导入前明确告知                               | 不保留                   |

不承诺 Office 无损往返。DOCX/MD 为首版结构格式主通道；PDF 的输入只读，输出是有限排版能力。
