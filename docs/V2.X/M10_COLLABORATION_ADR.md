# M10 本地协作身份与权限决策

2026-09-30，用户接受 M9，并选择先实现本地分享包、审阅与意见回收。代码基准为 `9c76837`，数据库从 Schema 31 顺延。本决策服务于本地协作闭环，在线协作和外部账号连接仍未实施。

## 身份与成果归属

当前桌面数据目录只有一个本机身份，用随机标识区分安装。显示姓名可修改，不能作为认证凭据。既有及新建成果归属于该本机身份；导入分享包保存为独立收件记录，不取得原成果的修改权限，也不自动加入资料库或发送给模型。

## 分享与审阅

分享固定为一个已保存的 Markdown 或纯文本文档成果快照。用户选择只读或允许反馈；包中只包含分享标识、正文、内容摘要、标题、格式和对外显示姓名，不包含本机路径、工作区目录、密钥、聊天或资料附件。外部引用标记保持正文原样，来源附件不随包发送。

审阅人在独立收件箱中阅读、填写意见，可提供完整建议稿。反馈只是一份不可信提案。接收端依据本机保存的分享记录解析目标，不接受外部包指定本机文件或成果 ID。姓名显示为对方填写，未经认证。重复导入应幂等；同一标识对应不同内容时拒绝。

本机撤销分享后拒绝后续反馈和未应用提案；已经传出的文件副本无法远程收回。权限描述只约束本应用处理反馈，不承诺限制接收人复制文件。

## 同步与冲突

通过文件手动交换，无服务器、账号注册或后台同步。分享绑定正文 Hash 和成果 Revision；导入意见先核验分享授权，允许阅读过期意见；创建审阅及应用前均校验当前基线。基线变化后不自动合并，要求重新分享。修改经过统一 Review，用户接受后才写入，支持原有撤销。

## 加密与审计

首版分享包是有大小与结构限制的 JSON 文件，不包含可执行脚本或压缩附件。内容 Hash 用于一致性校验，不是身份签名。文件不加密，界面明确告知导出的正文可被持有文件的人读取；需要保密传输时由用户选择其文件传递方式。在线身份认证、端到端加密和签名需要独立设计，不能将本机身份冒充团队账号。

记录创建分享、撤销、导入、保存反馈、创建审阅等本机事件，事件不复制正文。清除本地数据同时删除身份、分享、收件和审计记录。历史迁移保持原成果、工具与资料不变。

## 外部资料边界

本阶段的分享包不注册为检索来源。后续连接器必须经过来源授权快照、检索过滤与发送清单；外部服务凭据不能交给模型。后续服务端协作需要独立的身份、资源 ACL、同步与冲突协议，不能沿用文件中的自报姓名作为授权依据。
