## 1. 配置模型

在设置中选择已有云端服务并填写自己的 Key，或者使用 OpenAI-Compatible 配置本地服务，例如运行中的 Ollama / LM Studio 的 `/v1` 地址及实际模型名。无鉴权的本地服务可不填 Key。保存并测试连接，选择为当前服务。

本版没有内置默认服务；本地检测到服务不代表自动下载或安装模型。

SiliconFlow 请求会显式使用非思考模式，以便总结和写作直接返回可审阅正文。可用 `Qwen/Qwen3.5-35B-A3B` 复验此前“长时间未返回有效正文”的问题；修正后不应因只返回思考字段而在 60 秒时超时。Provider 本身拥堵、断网或没有返回任何数据时，仍应正常显示超时错误。

## 2. 从成果开始写作

1. 新建或打开 Markdown / TXT 文档成果，在右侧输入写作要求。
2. 点击输入框内“上下文”，默认不勾选“本次发送当前成果的已保存正文”。可选资料库文件、目标工作区已授权文本资料及资料包。
3. 关闭资料选择，点击“发送”，检查接收方、任务要求、资料名称与字数；取消后不应调用模型。资料选择弹窗内也可直接“规划发送范围”。
4. 确认生成，观察“正在等待模型响应…”切换为“正在生成…”并展示流式正文。本次要求和实际发送清单应保留。生成结束应出现提案，原文仍未修改。
5. 先拒绝一次，原文应保持不变；重新生成后接受，正文才更新。
6. 点击“撤销本次 AI 修改”，应恢复修改前正文。也可通过成果已有历史版本查看变更。

需要改写原文时，显式勾选发送已保存正文；未保存或待恢复的草稿需先处理。

对比工作区授权资料的助手与成果助手：模型选择、上下文入口、可调高度输入框及发送/停止按钮应保持一致。成果助手顶部应标明目标成果；生成时输入框可阅读、不可修改，停止后恢复输入。蓝色说明可关闭，关闭不改变资料选择。

同一应用会话内，首次确认后只修改写作要求并再次发送，不应重复弹出发送清单确认。更换模型、处理位置、资料选择、资料内容或长文检索片段后，必须重新确认；关闭并重启应用后也重新确认。敏感资料的批准仅复用于完全相同的范围。

取消发送清单确认时，输入框文字应保留。确认成功并正式开始生成后，输入框应清空，已发送文字继续显示在上方“本次要求”中。停止或失败后输入框恢复可编辑；空输入不能再次发送。

编辑成果或填写写作要求后，点击顶部“首页”，再点击“工作台”。应回到同一成果，并保留尚未保存的成果草稿、写作要求和资料选择。明确从首页创建新任务或打开另一成果时，才切换目标。

在专业模式下处理成果时，点击左侧由系统目录选择器授权的工作区文本文件。应先显示“打开工作区文件？”；选择“留在当前成果”不得跳转或丢失编辑内容，选择“切换并打开”后才打开该文件。成果有未保存修改时，提示应明确说明会先保留恢复草稿。

在资料库管理界面移除一项工作区授权资料，再返回首页。该资料应同时从首页资料列表消失；不应残留条目，也不应在再次操作时提示“资料来源不存在或未获当前工作区授权”。

## 3. 首页任务

选择一个任务模板并填写问题。“创建结构草稿”继续离线可用；“AI 生成正文”进入模型选择、资料确认与审阅。接受后创建可编辑的成果，生成过程中不应提前出现空成果。

## 4. 失败与恢复

- 生成过程中停止：不得写入半段正文；之后可重新规划和生成。
- 配置错误地址或错误 Key：显示失败，原文不变，不自动改用另一服务；修正后可重试。
- 如提示成果版本冲突：保留当前内容，允许拒绝提案或另存副本。
- 重启后，已保存成果应保留；未应用的成果提案可重新打开审阅，不自动写入。

反馈时只需说明哪一步、实际表现和期望表现。确认本阶段通过后，代理才会按你的授权进入下一阶段。
