# M10 本地协作产品验收

本轮只验收本地协作；未开始在线账号、同步服务器或外部连接器。工程验证由代理完成，用户只需检查产品体验。

## 启动

使用 `logs/m10-collaboration-review/a2ui-terminal.exe`，或在仓库运行 `npm run desktop:dev`。分享与审阅不调用模型，也无需配置服务。

## 一次完整往返

1. 在工作台打开已保存的 Markdown 或纯文本文档成果，点击「协作审阅」。在「我的协作署名」填写姓名并保存。
2. 选择「允许返回审阅意见」，点击「创建并导出分享包」。文件为 `.a2uishare`，包含标题和正文快照。
3. 将文件交给装有同版程序的审阅人。审阅人从「成果 → 协作收件箱 → 导入协作包」打开它。也可在同一台程序中导入刚才的分享包体验流程。
4. 填写意见；如要直接建议改稿，勾选「附上建议修改稿（全文）」并编辑。点击「保存并导出意见包」，将文件交还作者。保存对话框取消时，意见仍保存在本机。
5. 作者导入意见包。此时正文应完全不变；点击「审阅建议修改」，核对修改前后内容，再选择接受或拒绝。
6. 接受后检查正文，点击「撤销刚才的协作修改」检查恢复。关闭协作面板后，也可使用成果原有撤销和历史版本。

## 体验边界

- 仅填写评论时，可以阅读评论，不显示直接应用修改入口。
- 「仅阅读」分享不提供意见编辑器。
- 先分享，随后修改并保存原成果，再导入旧建议：可以阅读意见，但不能把旧建议直接覆盖到新正文。请重新分享最新版。
- 撤销分享后，后续意见不能继续导入或应用。已经交出的文件仍能被阅读。
- 关闭含未保存意见的面板或切换收件记录时，出现放弃更改提示。
- 重新启动后，署名、已创建分享、收件记录和已保存意见仍在。蓝色说明提供关闭按钮。

## 本期范围说明

协作包是明文文件；姓名为自报，未经账号认证。分享包不附带资料来源、聊天、API Key 或本机路径，正文中原有的链接和引用标记保留为文字。收件内容按文字显示，不加载其中的图片或链接。

本期仅支持文档成果的 Markdown / 纯文本快照，不分享整个工作区、资料包或场景工具状态。收件箱与分享列表显示最近 100 条；历史记录仍保存在本机。建议稿采用全文审阅，暂不支持逐条讨论、逐段合并、在线共同编辑或批注定位。

人工验收通过后再决定后续范围。本轮完成不等于自动启动在线协作或外部来源接入。
