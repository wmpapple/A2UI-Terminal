# M1-B AI 接入决策

日期：2026-09-23。用户已确认 M1-A 验收通过并授权实施 M1-B。

用户对接入策略的明确选择是：**先支持自带 API Key（BYOK）和本地模型，暂不提供内置服务**。此记录更新 M0 ADR-006 中的待选择状态，不将以前的阶段验收推定为策略授权。

- 云端服务使用用户配置的 Endpoint、模型与 Key，凭据继续保存在 Windows Credential Manager；不将密钥打进桌面包。
- 本地模型使用 OpenAI-compatible HTTP/SSE 接口。loopback 服务无需鉴权时允许空 Key，需要鉴权时使用用户配置的 Key。保留本地服务检测与连接检查。
- 成果助手和首页 AI 任务共享可信生成服务、Manifest、流式传输、取消、错误处理和 Review 写入边界。
- 用户明确确认实际接收方及本次资料范围后才发起请求。失败不自动更换模型、服务或处理位置；重试重新规划和确认。
- 不建设默认服务、登录计费、平台额度或上游代理。历史 O-08 的“默认 AI 尚未实现”事实保留，但不再作为本次 BYOK + 本地版本的发布前置依赖。
- 本阶段不宣称无需配置、不宣称所有自定义模型达到同一写作质量，也不承诺 95% 满足全部预期。M2 才建立固定任务 Eval 和 Prompt 版本机制；本阶段不提前实施 M2。

阶段门保持不变：代理完成工程验证与构建，用户只做产品功能验收。M1-B 验收通过并明确授权前，不进入下一阶段。
