2026-09-30。用户明确验收通过 M9，并选择「导出分享包、他人审阅、导入意见后确认修改」。本轮基于 `9c76837` 开始，保留 M9 的工具自动保存与主动保存成果规则。

## 交付范围

- Schema 32：本机身份、成果归属、分享、收件、审阅关联和最小审计记录。迁移回填既有成果归属；清除本地数据清理协作数据并生成新的本机身份。
- 工作台「协作审阅」及成果页「协作收件箱」：署名、只读或可反馈分享、原生导出/导入、意见与可选全文建议稿。
- 作者接受建议前显示原稿和建议稿；复用统一 Review 与成果撤销。外部包不能指定本机成果 ID 或文件路径。
- 创建和应用建议时检查分享授权、正文摘要、成果修订以及未保存草稿；旧版本或撤销的分享不能写入。缺少审阅关联时拒绝应用。
- 协作包按文本显示，不执行 HTML、不加载图片、不注册为检索资料、不触发模型请求。原生选择器决定文件路径，原子导出避免部分写入。
