# M7 禁用词漏提示修复

2026-09-29，仍处于 M7 人工验收，未授权下一阶段。

## 实际原因

只读核对本机写作偏好和已保存审稿记录后，确认全局与工作区均启用了“赋能”。用户文档包含验收说明的外层三反引号和 `markdown` 标记，整篇成为代码块；规则按设计跳过代码。因此本次没有提示并非偏好未保存。

审稿面板新增可关闭的代码块包裹提示，说明删除首尾标记、保存、重新检查的操作。没有自动改动用户正文、偏好或审稿记录。验收说明同步明确只复制正文。

## 同时修复的漏检

- 桌面端术语与禁用词改用 Markdown 文本事件，覆盖标题、紧凑列表和引用；仍排除行内代码和代码块。
- 浏览器演示补齐禁用词检查，涵盖重复出现、偏好变更与忽略状态。
- 本地规则版本升为 `critic-v1.1`，浏览器缓存键同步升级，避免复用旧结果。

- Rust 审稿集成测试 11 项通过，包含新增结构覆盖与 UTF-16 定位回归。
- 前端相关测试 3 个文件、12 项通过，包含粘贴代码块时的解释提示。
- TypeScript、ESLint、Rust Clippy 和桌面构建通过。
- 真实 Tauri/WebView2 流程使用隔离数据、关闭凭据、回环模拟服务，验证禁用词提示、忽略恢复、显式发送确认、审稿只读及接受提案后写入。该测试不表示真实模型质量已认证。
