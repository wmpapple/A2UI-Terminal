# S4.1 最近成果与统一搜索人工验收

> 范围：只验收 S4.1；通过前不得开始 S4.2。

> 真实授权、撤销和索引重建必须在 Windows 桌面应用中验收。Web Mock 只用于界面演示，不能代替本单。

## 准备

1. 完全关闭旧的桌面应用和开发进程。
2. 在项目根目录执行 `npm run desktop:dev`。
3. 打开一个真实工作区，准备一个可保存的 Markdown 成果、一个普通 Markdown 资料和一个敏感排除文件（例如 `credentials.json`）。

本机若再次遇到随机 Rust 编译崩溃，可在新的 PowerShell 会话中使用以下临时设置：

```powershell
(Get-Process -Id $PID).ProcessorAffinity = 1
$env:RUSTUP_TOOLCHAIN = 'stable'
$env:RUST_MIN_STACK = '33554432'
$env:CARGO_INCREMENTAL = '0'
$env:CARGO_BUILD_JOBS = '1'
npm run desktop:dev
```

关闭该 PowerShell 后，以上设置即结束。

## M01 最近成果来自 Result

1. 新建 Markdown 成果，标题设为 `S4.1 发布纪要`，正文保存 `S41-RESULT-BODY-0916`。
2. 返回首页查看“最近成果”。
3. 点击该成果的“继续处理”。

预期：最近成果显示新建 Result，而不是聊天会话；点击后打开正确成果，正文和保存状态不变。

## M02 搜索成果标题和正文

1. 在首页“搜索本地内容”依次搜索 `S4.1 发布纪要` 和 `S41-RESULT-BODY-0916`。
2. 检查两次结果均标为“成果”，且摘要不显示数据库路径或托管目录路径。
3. 点击“打开成果”。

预期：标题和当前已保存正文均可命中；直接打开正确成果，不创建新聊天或新文件。

## M03 搜索已授权资料和资料包

1. 新建普通 Markdown 文件，写入唯一文本 `S41-AUTHORIZED-SOURCE-0916`，通过“添加资料”明确授权。
2. 在发送清单中把该资料保存为资料包，名称使用 `S4.1 发布资料包`。
3. 回到首页，分别搜索正文唯一文本和资料包名称。
4. 对资料结果和资料包结果分别点击“用此资料开始任务”。
5. 在工作台打开“修改发送清单”。

预期：已授权正文和资料包安全元数据可搜索；点击只把对应来源或资料包选入当前任务的发送清单并打开工作台，不会自动发送消息；实际发送前仍要求查看并确认范围。

## M04 敏感路径和未授权内容不进入搜索

1. 用系统记事本在电脑测试文件夹中创建 `credentials.json`，写入测试文本 `S41-SECRET-MUST-NOT-INDEX`，不使用真实凭据。这里的创建不是指加入应用；敏感文件名即使内容为空也会被拒绝。
2. 分别从首页“选择资料”、专业模式工作台“添加文件”和简单模式“选择文件”选择它。三个入口都应显示“确认读取范围”，列出敏感路径拒绝原因和脱敏副本建议，确认按钮不可用。取消后，再同时选择一个普通 `.md` 文件和该敏感文件，确认只有普通文件可勾选，点击确认后只有普通文件加入工作区。
3. 在首页搜索文件名和正文唯一文本。
4. 再准备一个从未通过“添加资料”授权的普通文件，写入 `S41-UNAUTHORIZED-MUST-NOT-INDEX` 并搜索。

预期：两个文件均无搜索结果；应用不扫描整个工作区。搜索范围说明明确排除聊天、Prompt、AI 回复、调试信息、敏感路径和未授权文件。

## M05 撤销授权、工作区隔离和失败保持

1. 确认 M03 普通资料仍能命中后，在资料列表取消其授权。
2. 再次搜索 `S41-AUTHORIZED-SOURCE-0916` 和 `S4.1 发布资料包`。
3. 切换到另一个工作区，搜索第一个工作区中的资料正文或资料包名称。
4. 输入空白搜索或超过 200 个字符的搜索词。

预期：撤销后资料命中立即消失，失去全部有效来源的资料包也消失；另一工作区看不到前一工作区资料；无效输入给出可理解的错误且不改变成果、授权或历史。

## M06 修复搜索和跨重启重建

1. 先确认 M01 成果仍可按正文命中。
2. 点击“修复搜索”，观察成功提示。
3. 重新搜索同一正文并打开成果，核对正文未变化。
4. 完全关闭应用后重新执行 `npm run desktop:dev`，再次搜索并打开该成果。

预期：修复只清空可重建的本机内存索引，不修改或删除 Result、Revision、资料包或原文件；修复后和重启后首次搜索会从当前授权数据重建并正常命中。

## P0 明确限制

- 搜索使用本机确定性词法检索，不是云端搜索或语义 Embedding；不会把索引正文持久化到 SQLite。
- 成果搜索覆盖未归档 Result 的标题与当前可读取正文；资料正文和资料包元数据只覆盖当前工作区仍获授权的来源。
- 图片只按安全名称参与搜索，不做 OCR，也不索引图片二进制或预览数据。
- “用此资料开始任务”只准备发送清单，不会自动向 Provider 发送资料。
