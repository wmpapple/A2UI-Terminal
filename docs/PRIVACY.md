# 隐私与本地数据说明

## 本地保存的数据

A2UI Terminal 桌面版会在应用数据目录的 SQLite 中保存工作区授权记录、Result 成果元数据、Task 状态与结构化回答、内置模板版本、会话、完整消息正文、显式上下文元数据、崩溃恢复草稿、Review 候选/逐块决定、文档版本、Patch 审计和 A2UI Inspector 记录。Review 候选可能包含 AI 建议的完整文本或修改片段，以便待审阅状态跨重启恢复；这些内容只保存在本地，不进入诊断或匿名指标。A2UI Result 还会保存已经可信校验的 Surface 状态快照，使成果不依赖来源会话继续存在。失败的 A2UI 检查记录默认仅在本机保留供排错，用户可二次确认后单条永久删除；该动作不删除聊天、Surface、成果或文件。模板只保存字段规则和空白结构，不保存用户源文；Task 回答仅保存在本机。会话永久保留，文档版本默认保留 30 天；每个文件的普通自动保存/恢复历史最多保留最近 100 条，Patch 审计版本不受该数量上限影响。

崩溃草稿包含尚未写入磁盘的工作区或 Result 编辑正文、基础磁盘 Hash、草稿正文 Hash 和更新时间。它只保存在本地 SQLite；启动或打开对应成果时用于发现待恢复编辑，并在磁盘内容已与草稿一致、真实保存成功或用户明确保留磁盘版本后删除。首页只读取恢复成果的标题、ID 和更新时间，不读取草稿正文。

schema v16 还会在本机保存 Task 的受控执行意图，以及 Export Job 的成果/版本 ID、格式、状态、目标路径、文件名、输出 Hash 和脱敏错误码，用于判断崩溃发生在文件提交前还是提交后。导出绝对路径和 Hash 不会返回前端恢复摘要，不进入诊断或匿名指标；启动不会根据记录自动重新导出或覆盖目标。

API Key 不写入 SQLite、localStorage、日志或项目文件，只保存在 Windows Credential Manager。从命令参数和凭据库取得的临时 Key 字符串会在离开作用域时清零；更新配置失败会恢复旧 Key，前端只能读取是否已配置。Web Mock 不读取上述桌面数据。

## 匿名产品指标

匿名产品指标默认关闭。关闭时不会向 `product_events` 写入产品事件，也不会向网络发送任何指标。用户完成首次保存、导出或已审阅修改后，应用只把“可以显示一次非打扰邀请”记为本地设置；不会默认勾选开关、阻断流程或把完成动作追溯写成匿名事件。

用户主动开启后，schema v14 的 `product_events` 只保存固定事件名、事件版本、应用版本、Windows 平台和强类型白名单属性。属性只允许布尔结果、固定动作类别、固定错误类别、本机/云端类别和耗时区间；不保存安装 ID、用户 ID、工作区/会话/成果 ID。任务完成率、审阅采用率、修改接受率、撤销率、保存/导出率和发送清单确认率均由本机固定事件计数计算，不使用 DAU、消息数或模型调用量冒充成果指标。

设置中的“查看将发送的数据”在开启前也可以打开，展示完整公共字段、逐事件字段和永不采集清单。文档正文、Prompt、AI 回复、文件名、路径、图片、API Key、具体 Endpoint/模型 ID、姓名、邮箱、身份信息及本地索引内容永不进入事件。当前版本尚未配置匿名指标接收端，因此即使开关开启，事件也只保存在本机，不会上传；O-06 确定接收端、保留期、聚合和删除机制前不得增加上传网络路径。

用户随时可以关闭匿名指标；当前实现会同时停止后续采集并清除已保存的本机产品事件计数。“一键清除所有本地数据”同样会清除 `product_events` 和 `telemetry_settings`，随后恢复为默认关闭。Web Mock 不访问桌面遥测表。

简单/专业模式偏好仅在本地浏览器存储中保存固定值 `simple` 或 `professional`，不包含文档正文、Prompt、AI 回复、文件名、路径、Endpoint、Provider 配置或密钥。切换模式不会复制、上传或迁移 Result、Task、会话和上下文授权数据，也不会改变任何安全权限。

首次引导完成状态仅以 `a2ui.onboarding-complete.v1=true` 保存在本地浏览器存储中。引导选择的目标不持久化；资料正文、文件名、路径和隐私确认内容不会写入该偏好。首页最近成果从本地 Result 元数据读取，不从聊天正文或会话标题推断。首页资料区同时支持受控系统选择器和 Tauri 原生桌面拖放；React 只注册资料区的逻辑坐标，原生拖入路径由 Rust 接收，前端不会读取 `DataTransfer` 中的路径或正文。

待确认 ImportBatch 只在 Rust 进程内存保存随机批次/文件标识与规范化本地路径，不写入 SQLite、localStorage、日志或遥测。主窗口原生路径通过 Rust `WindowEvent::DragDrop` 接收并只在精确命中已注册资料区后检查；区域外不建立批次。前端只能通过系统选择或脱敏 `import-drop-outcome` 事件看到文件名、扩展名、大小、能力、失败原因和替代方式，看不到绝对路径。主窗口只获得接收和卸载该事件监听所需的权限，不获得事件发送权限。取消、应用退出、新选择或“清除所有本地数据”会使待确认批次失效，不建立文件授权。确认后仅被勾选且由 Rust 重新检查为可读的文件建立本地授权引用。导入不会修改或复制来源文件，不调用 Provider，不上传内容；S2.1 中 CSV/XLSX/图片只做能力说明，不读取为 AI 上下文。

用户主动新建的 Markdown/纯文本成果保存在应用数据目录下的 `my-results`，正文仍只在本机文件和 SQLite 版本历史中处理。前端不会获得该目录的绝对路径，只持有 Result ID、`result://` 不透明引用、打开时正文和 Hash。通用工作台聊天已经使用 S2.3 Context Manifest；成果专用 AI 区仍不自动发送正文，待后续统一 Result Context/Review 链路接通。导出入口在 S2.8 前不会创建外部文件。文件名只用于本地创建和冲突校验，不进入匿名指标、诊断报告或远程请求。

AI 建议新建文件时，接受 Review 前不会创建空文件、Result 或 Revision。接受后只在 `my-results` 中创建已审阅的文本成果；拒绝不写磁盘。同名或外部变化不会覆盖，系统会要求保留当前、另存候选副本或重新生成。用户主动撤销 AI 创建时，只有文件 Hash 仍与已审阅版本一致才会删除本次创建的托管成果；检测到用户后续修改会停止删除并报告冲突。

## 发送给 AI Provider 的数据

通用工作台只有 Rust 生成的发送前 Context Manifest 中明确列出的选区、已授权文本/表格和最近消息才进入请求。Manifest 正文只在进程内存保留最多 10 分钟并在一次请求消费后失效；SQLite `context_snapshots` 只保存来源标签、类型、大小、内容 Hash、排除原因、处理位置和敏感布尔值，不保存文件上下文正文。未选择内容不会被 Rust 读取进发送快照；`.env`、私钥、证书、凭据文件和 `secrets/**` 默认排除。当前文本 Provider 合同不支持可信视觉输入，图片会带原始 Hash 明确列入“不会发送”，不会静默丢弃后声称已理解。

每个对话只在首次发送时主动弹出发送清单；后续请求仍为新 Prompt 生成并消费新的 Rust Manifest，但在用户已确认的范围和 Provider 未变化、且没有新敏感风险时后台完成。范围、文件内容或 Provider 变化时，应用只提示用户点击“修改发送清单”，不会主动弹窗或调用 Provider。后台清单新发现敏感内容时不会自动视为同意，必须等待用户主动打开清单并明确确认。

长文和多来源由 S2.4 在本机自适应处理。短内容按全文发送；长内容只选择与当前问题相关的结构分块；短当前文件与其他长资料并用时采用混合策略。清单会展示实际策略、来源、分块数量和字符起止范围，用户仍可取消来源或缩小范围。检索不改变“只有明确授权内容才可发送”的边界。

S2.4 P0 不下载、不调用本地或云端 Embedding 模型。分块正文、词频和 BM25/中文 bigram 索引只保存在 Rust 进程内存，不写入 SQLite、临时文件、日志或遥测；退出应用即自然释放。切换或删除工作区、撤销来源、“清除本工作区检索索引”和“一键清除所有本地数据”会立即释放对应内存索引并使尚未发送的清单失效。发送前 Rust 还会复核来源授权和内容 Hash，授权已撤销或文件已变化时拒绝旧清单。

处理位置由 Rust 根据当前 Provider 配置复核：只有明确的 `localhost`、`127.0.0.1` 或 `[::1]` 端点显示“本机处理”，其他端点均按“云端处理”。云端清单疑似包含 Secret 时必须额外勾选确认；切换 Provider 或修改 Endpoint、Model、Temperature、Proxy 后，旧清单不能消费。不同云端 Provider 的数据处理规则仍由相应服务条款决定。

## 诊断导出

脱敏诊断文件只包含：

- 应用版本和数据库 Schema 版本；
- 操作系统与 CPU 架构；
- 工作区、会话、消息、草稿、版本、Task、Result、Review、Patch、A2UI 和本机产品事件记录数量。

它不包含消息正文、文件内容、工作区名称/路径、API Key、Endpoint、代理地址或原始日志。请在发送诊断文件前仍进行人工检查。

## 删除与保留

- 删除某个工作区：同步删除该工作区在应用中的会话、消息、草稿、版本、Patch 与 A2UI 历史；不删除磁盘项目文件。
- Result API 只返回 `result://` 不透明引用，不返回真实文件绝对路径；旧文件/Surface 只在显式打开时惰性关联，不扫描或复制整个工作区正文。
- 文本 Result 新建只接受 `.md`、`.markdown`、`.txt` 单层名称，拒绝绝对路径、穿越、非法字符、保留名和静默覆盖；失败时不保留半成品 Result/Revision。
- 一键清除所有本地数据：删除全部应用数据库业务数据和 Windows Credential Manager 中已知的 Provider Key；不删除磁盘项目文件。
- 卸载：是否保留应用数据取决于安装/卸载器选择；正式发布验收必须验证并向用户展示实际策略。

所有清理操作在 UI 中明确说明影响范围，并需要二次确认。
