# S1.4 新手引导与首页人工验收

> 阶段状态：实现与自动验证完成；旧 Surface 占用与永久删除生命周期已修补，等待人工复验  
> 验收范围：ONB-01、HOME-01、HOME-02 的 S1.4 部分  
> 明确不含：S1.5 成果专用工作台、真实内置模型、完整拖放导入、表格/动态工具生成、导出

## 1. 启动方式

桌面开发实例：

```powershell
npm run desktop:dev
```

Web Mock：

```powershell
npm run dev
```

首次引导只在本地保存一个完成标志。若要重新检查，可以在首页点击“查看新手引导”；不需要清理业务数据。

## 2. 通过规则

- 所有“阻断”项必须通过。
- 不得把本地结构草稿描述为 AI 已生成正文。
- 不得强制配置 API Key、Endpoint、Provider 或其他技术参数。
- 最近区域必须显示 Result 成果，而不是聊天会话。
- 表格分析和表单/清单/小工具入口必须诚实说明后续开放，不能返回假结果。

## 5. 已知阶段边界

- “最近成果”已经是独立 Result 摘要；把某个托管 Result 重新载入专用成果工作台属于 S1.5。目前后续按钮进入共享工作台，不声称已经打开对应托管文件。
- 首页拖放区复用现有受控选择窗口；CSV/XLSX、图片、导入清单、处理方式说明和完整原生拖放接入属于 S2.1/S2.2。
- “分析表格或数据”和“制作表单 / 清单 / 小工具”只提供固定一级入口及真实能力边界，分别等待 S2 和 S3。
- O-08 尚未关闭，本阶段只验证 S1.2 已有的本地结构草稿闭环；真实平台内置模型、额度、服务端鉴权和滥用控制没有实现。
- A2UI 永久删除不可撤销；当前只支持逐个删除并强制确认，不提供批量清空。关闭仍是保留历史的非破坏性操作。

## 6. 缺陷分级

- **阻断**：首次引导无法跳过；首页不是固定六类；必须配置 Key；会议纪要/文档总结无法形成 Result；最近区域显示会话；旧 Surface 自动占用恢复后的主视图或无法关闭；永久删除无确认、取消仍删除、确认后重启恢复、误删其他数据或留下孤儿 Result；未实现能力返回假成功；出现未授权读取或内容外发。
- **严重**：资料选择不可用；隐私确认无法完成；引导每次启动重复弹出；中英文任一核心路径不可操作；Task 失败但界面显示成功。
- **一般**：布局、文案、间距或非关键响应式问题，不影响核心闭环。
