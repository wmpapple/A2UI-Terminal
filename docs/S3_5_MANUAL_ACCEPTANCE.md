# S3.5 个人安全 Surface 模板人工验收

> 范围：只验收 S3.5；通过前不得开始 S4.1。

> 个人模板只在 Windows 桌面应用中工作。Web Mock 不会写入真实 SQLite，不能代替本单验收。

## 准备

1. 完全关闭旧的桌面应用和开发进程。
2. 在项目根目录执行 `npm run desktop:dev`。
3. 打开一个真实目录工作区，确认“工作台”中可以正常生成并使用 A2UI 交互成果。

本机若再次遇到随机 Rust 编译崩溃，可在新的 PowerShell 会话中使用以下临时设置：

```powershell
(Get-Process -Id $PID).ProcessorAffinity = 1
$env:RUSTUP_TOOLCHAIN = 'stable'
$env:RUST_MIN_STACK = '33554432'
$env:CARGO_INCREMENTAL = '0'
$env:CARGO_BUILD_JOBS = '1'
npm run desktop:dev
```

关闭该 PowerShell 后，以上设置即结束。

## M01 保存安全模板并清空当前值

1. 在工作台生成一个不修改文件的检查表或表单 Surface，例如：

   > 生成一个中文交互检查表，不要创建或修改文件。包含姓名输入框、状态选择和两项检查项，所有字段都可以修改。

2. 在输入框、选择项和检查项中填写容易辨认的临时值，例如 `S35-不应保存-0916`。
3. 点击 Surface 顶部的“保存为模板”，输入唯一名称 `S3.5 安全模板`，确认保存。
4. 观察说明文案：系统应明确告知会清空当前填写值，并且不会保存文件修改候选。

预期：保存成功并提示可在“模板”页重新打开；原 Surface 的当前显示和值不被保存动作改变；界面不显示数据库路径、绝对路径或内部快照 JSON。

## M02 模板列表和权限说明

1. 点击顶部导航“模板”。
2. 找到 `S3.5 安全模板`。
3. 检查卡片中的 A2UI 版本、Catalog、绿色“可用”状态和“允许的操作”。

预期：普通用户能看到类似“可在本机修改界面字段”“提交只记录在本机，不会发送到外部”的说明，而不是只有内部 ID；页面说明每次打开都会重新进行安全检查，也明确当前填写内容、聊天和原始模型消息不会保存。

## M03 安全打开并验证独立状态

1. 点击模板卡片的“安全打开”。
2. 应自动回到工作台并打开一个新的交互成果。
3. 检查 M01 中的 `S35-不应保存-0916` 不存在；文本、日期、勾选项恢复为空白或安全默认值。
4. 在新界面输入 `S35-新实例`，确认交互正常。
5. 从工作台交互成果历史中切回原 Surface，确认原 Surface 没有被新实例修改。

预期：重开得到新 Surface，而不是直接恢复或覆盖原 Surface；模板实例之间的数据互不影响。

## M04 跨重启和来源生命周期

1. 关闭桌面应用后重新执行 `npm run desktop:dev`，打开同一工作区。
2. 进入“模板”，确认 `S3.5 安全模板` 仍存在并可安全打开。
3. 回到工作台，永久删除 M01 的来源 Surface；若它有自动关联的小工具 Result，按现有提示确认其生命周期影响。
4. 再进入“模板”并安全打开 `S3.5 安全模板`。

预期：模板跨重启持久存在；删除来源 Surface 后模板仍能通过当前版本/Schema/权限复验并创建新 Surface；真实工作区文件不被删除或修改。

## M05 文件修改候选必须拒绝保存

1. 生成或打开一个带 `request_patch` 的 S3.3 审阅卡，例如：

   > 生成一个中文交互卡片，不要立即创建或修改文件。提供“保存为成果”按钮，点击后提出一个 Markdown `create_file` 候选并先进入审阅。

2. 不点击审阅按钮，直接点击 Surface 顶部“保存为模板”，输入新名称并确认。

预期：点击“保存模板”后，弹出“保存个人模板失败”对话框，明确提示“包含文件修改候选的交互成果不能保存为个人模板”。点击“关闭”可返回原保存窗口，名称仍保留；模板页没有新增该模板；不会创建 Review、Result 或真实文件。

## M06 工作区隔离与删除边界

1. 切换到另一个真实目录工作区，打开“模板”。
2. 确认看不到第一个工作区的 `S3.5 安全模板`。
3. 切回第一个工作区，在模板页点击“永久删除”，阅读二次确认说明后确认。
4. 返回工作台检查 M03/M04 已打开的 Surface 和已有成果。

预期：个人模板严格按工作区隔离；删除确认明确说明只删除模板；删除后模板卡片消失，但既有 Surface、Result、Revision 和真实文件保持不变。取消删除时应零变化。

## P0 明确限制

- 本阶段保存的是受信本地 Catalog 的声明式 Surface，不是通用 Prompt、网页或代码模板。
- 不保存当前填写值、聊天、Prompt、Context Manifest、Inspector/Provider 原文、绝对路径、Result/Revision 或文件正文。
- 不接受 HTML、JavaScript、React、iframe、URL、动态 npm、Shell、系统命令、远程资源或任意模型代码。
- 版本、Catalog、Schema、组件树、资源上限或 Action 权限在未来发生不兼容变化时，模板会显示“已失效”并禁止打开，不会尝试猜测或自动修复。
