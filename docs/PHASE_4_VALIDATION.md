# 阶段 4 验收记录

验证日期：2026-08-06

## 已实现

- Rust 后台系统目录选择器，不接受前端提供的任意绝对路径；
- 最近工作区、授权恢复和工作区数据库记录删除；
- 常见文本/代码扩展名文件树，忽略 `.git`、依赖、构建、虚拟环境和 `secrets`；
- 2 MB 大小限制、UTF-8 检测、路径穿越与符号链接越界防护；
- Markdown 编辑/预览，以及 TS、JS、JSON、Python、YAML 等纯文本代码编辑；
- 多 Tab、脏状态、250 ms 草稿保存、1 秒真实文件自动保存；
- SHA-256 基础版本冲突检测，外部变化时不覆盖文件；
- 安全草稿自动恢复，以及冲突草稿的显式恢复/丢弃；
- 删除工作区记录时通过外键级联删除会话、版本和草稿，不删除项目文件。

## 产品验收步骤

1. 使用 `npm run desktop:dev` 启动桌面应用；
2. 点击“打开文件夹”，选择一个包含 JSON、TS、JS、Python 或 YAML 的测试目录；
3. 打开多个文件并切换 Tab，修改内容，确认约 1 秒后显示“已保存”且磁盘内容更新；
4. 修改编辑器内容后，在外部编辑器先修改同一磁盘文件，确认 A2UI 显示外部变更冲突且不会覆盖；
5. 修改内容后在草稿落库、自动保存前立即中断应用并重新打开，确认草稿可恢复；
6. 删除工作区记录，确认最近项目历史消失，但磁盘目录和项目文件仍存在；
7. 在 Web 模式确认仍显示 Mock 标签且不会出现真实目录数据。

阶段 5 在产品负责人确认前不开始。
