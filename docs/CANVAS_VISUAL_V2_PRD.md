# 画布可视化与视觉优化需求（V2）

## 依据与范围

本文件依据用户对空间画布的最新反馈，作为 [空间画布需求](SPATIAL_CANVAS_PRD.md) 的修订。画布仍在工作台内，与文件、我的工具并列；现有画布、位置、连线和旧数据须保留。本轮以可读性、可视化导入、图形化流程图和 AI 内容呈现为验收重点。本文件与旧文档冲突时以本文件为准。

## 1. 视觉与可读性

- 浅色、深色、护眼模式下，画布标题、工具栏、组件正文、表格、表单、操作按钮、弹窗和缩略图均须有可辨识的前景与背景；不能出现白底白字。
- 组件按用途提供柔和但明显不同的配色：笔记、清单、AI 摘要、流程图、成果表格/表单/工具、场景工具、行动、A2UI、分组。保持字体层级、留白和边框一致；选中与悬停有清楚反馈。允许给笔记设置底色、文字色及高亮色，并保存。
- 清单以清晰的复选项、进度和易读字体呈现；行动组件以状态、优先级、待办内容呈现。A2UI 按内容类型展示不同视觉布局，不统一包成单调白卡。

## 2. 组件库与可视化对象

- 新建组件库保留笔记、清单、流程图、AI 摘要、成果、我的工具、行动、A2UI 和分组；移除「引用」与「添加文件」入口。旧画布中已有引用/文件节点继续可读、可编辑。
- 「成果」只提供可视化成果：CSV 表格、清单、表单、工具。普通 md/txt 文档不得作为成果组件导入；不能仅按扩展名猜测类型，必须使用项目的 `ResultType`、内容格式和原有读取接口。CSV 展示表头、行列和可滚动表格；清单、表单、工具展示各自数据内容。无效数据展示具体错误并提供打开原成果入口，不能只剩标题。
- 「我的工具」列出工作台创建的场景工具；读取 `SceneToolView.surface` 和数据，在画布中安全预览输入、表格、状态、清单等 A2UI 内容。工具卡展示实际内容与来源；可以打开原工具。导入的快照随画布保存，以保证重启后可见；用户可主动刷新快照，源对象删除或读取失败时保留旧快照并提示。
- 已有 A2UI surface 可以导入，粘贴合法 surface JSON 也可导入；展示其内容，不执行持久化动作。无效 JSON 给出可理解提示，不能将整段原始 JSON 伪装成可视化内容。

## 3. 图形化流程图

- 点击「流程图」打开独立的图形化编辑弹窗：有矩形/圆角/菱形等节点工具、文本编辑、连接线、删除、布局和预览；用户通过拖动和连接构建流程，不要求输入 Mermaid。
- 保存后作为一个可缩放的流程图组件回到原画布；再次编辑回到同一编辑器，修改不会重置外层画布的位置和尺寸。关闭而不保存不得改变图。图内节点、连线、文字和布局随画布持久化。
- 旧版 Mermaid 与纯文本图解继续可读；旧内容可从编辑器转换/重绘，不静默丢弃。

## 4. AI 摘要与生成内容

- AI 生成仍需用户明确选择来源、确认发送范围、预览后添加；不自动覆盖手工内容。
- 生成要求返回可读的中文结构化内容。若模型返回 `document_patch` JSON 等项目协议，画布只提取其中适合展示的正文（例如 `changes[].content`），保留原始响应供检查；不得把整段 JSON 直接贴在节点上，也不得执行补丁。
- 摘要以安全 Markdown 样式展示标题、段落、列表、引用，来源和过期状态清楚。AI 图解可转为图形化节点/关系后让用户继续编辑；无法转换时仍显示可读文本与明确说明。

## 5. 数据、安全与兼容

- 扩展 `CanvasBlock` 的样式、结果快照、工具快照和流程图结构字段；沿用现有 SQLite JSON 保存、工作区隔离和乐观版本控制。导入只读取原对象，画布内编辑默认只改画布快照，不修改成果或工具源数据。
- 加载旧画布时兼容旧来源对象、引用、文件和 Mermaid 图解。新建入口调整不能删除旧内容。
- 渲染外部 CSV、表单、工具与 AI 文本时使用安全文本或现有安全 Markdown/A2UI 渲染器，禁止直接执行 HTML、脚本、工具动作或 `document_patch`。

## 6. 验收

1. 浅色、深色、护眼模式截图检查：各节点、工具栏、弹窗、表格和 A2UI 内容均可辨认；无白底白字。
2. CSV、清单、表单、工具成果与“我的工具”场景工具导入后均有实际内容；md/txt 文档不在导入列表；旧引用/文件节点仍可打开。
3. 流程图可纯图形操作创建、连线、编辑、保存、关闭重开；外层画布位置保持。
4. 笔记颜色/高亮持久化；清单与行动有清晰状态；A2UI 内容按组件结构展示。
5. `document_patch` 示例被转成可读摘要，原始 JSON 不出现在正文，补丁未执行；预览与手工编辑独立。
6. 类型检查、Lint、自动化交互测试、桌面构建和真实桌面回归通过；现有画布数据保留。
