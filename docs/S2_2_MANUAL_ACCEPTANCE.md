# S2.2 表格与图片读取适配人工验收

> 状态：**待用户人工验收**  
> 实施基线：`main` / `ab7d964` 之后的 S2.2 工作树  
> 验收范围：CSV/XLSX 基础数据、图片原始视觉来源、统一 `DocumentSource`、本地预览与安全边界  
> 阶段门禁：本文全部通过并由用户明确回复“**S2.2 验收通过**”前，不得开始 S2.3

## 1. 本阶段交付结论

- CSV 与 XLSX 已从“适配待开放”变为可逐项勾选的只读基础数据来源。
- PNG/JPEG/GIF/WebP 已从“图片上下文待开放”变为可逐项勾选的原始视觉来源；系统不会用 OCR 文本假装理解图片。
- 确认后所有来源均获得不透明 `sourceId`；绝对路径仍只在 Rust/SQLite 授权边界内。文本可进入编辑器，表格和图片不会被伪造成 `WorkspaceDocument`。
- 首页会列出“已授权的本地资料”，表格与小图片可本地预览，并持续显示“仅保留在本机，尚未发送给 AI”。
- 同一工作区的多次确认是追加而不是替换：后加入第二批资料后，第一批仍保留；重复加入同一来源时按持久化授权去重。
- 当前没有实现 S2.3 Context Manifest，也没有把表格、图片或正文送入 Provider。

## 2. 明确安全上限

| 类型          | 上限与行为                                                                                          |
| ------------- | --------------------------------------------------------------------------------------------------- |
| 单批          | 最多 20 个文件，总计不超过 100 MB                                                                   |
| CSV           | 2 MB；最多 10000 行、256 列、100000 单元格、单元格 32768 字符                                       |
| XLSX          | 25 MB；最多 32 个工作表；每表最多 10000 行、256 列；总计最多 100000 个网格单元格；单元格 32768 字符 |
| 图片          | 20 MB；单边不超过 32768 像素；总像素不超过 4000 万                                                  |
| 图片本地预览  | 8 MB 以内通过本机 `data:` URL 预览；更大图片只保留原始来源，不跨 IPC 复制预览                       |
| Office 压缩包 | 最多 2000 条目、单条目展开 25 MB、总展开 100 MB、压缩比 100:1                                       |

公式不会计算或执行。XLSX 只读取文件中已有的缓存值；以 `= + - @` 起始的文本和公式单元格会标为公式注入风险，原值保留，S2.8 导出时必须转义。宏不执行，外部链接不访问，嵌入图表不做结构化编辑或无损回写。

## 3. 验收准备

请完全停止旧的 `npm run tauri dev`，再从仓库根目录启动桌面开发版：

```powershell
npm run tauri dev
```

准备不含隐私内容的测试文件：

1. `s2-2-basic.csv`：包含表头、普通数字、带逗号的引号字段、跨行引号字段，以及一个以 `=2+2` 开头的文本单元格。
2. `s2-2-basic.xlsx`：包含至少两个工作表、文本/数字/布尔值、一个带缓存结果的普通公式；可再放一个超链接或外部关系用于观察安全提示。
3. `s2-2-image.png` 或 JPEG：建议小于 8 MB、尺寸清晰可辨。
4. 可选 `s2-2-large-image.png`：大于 8 MB 但不超过 20 MB，用于验证“保留原始来源但不生成本地预览”。
5. 可选超限 CSV：257 列或 10001 行，用于验证拒绝原因。

## 4. 人工验收矩阵

### M01 — CSV 受控读取

1. 在首页把 `s2-2-basic.csv` 拖入“添加资料”区域。
2. 在“确认读取范围”中检查该文件。

预期：

- 标签为“基础表格数据（只读）”，复选框可用且默认勾选。
- 页面明确显示行列/单元格/字符上限，以及“公式不计算、宏不执行、外部链接不访问”。
- 含 `=2+2` 时出现公式或公式注入风险提示。
- 确认后，首页“已授权的本地资料”出现该 CSV；点击“本地预览”，逗号字段和跨行字段没有被错误拆列，风险单元格使用提示色。

结果：`待验收`

### M02 — XLSX 基础数据与公式只读

1. 导入 `s2-2-basic.xlsx` 并确认。
2. 打开本地预览，切查首个工作表的文本、数字和公式缓存值。

预期：

- 标签为“基础表格数据（只读）”，可确认。
- 工作表名称、行列摘要正确；公式显示已有缓存值，但没有重新计算、弹窗或执行行为。
- 若包内含宏、外部关系或嵌入图表，确认页只给出警告；应用不打开链接、不加载网络内容、不运行宏。
- 不出现“完整复刻 Excel 格式/图表”或“可无损回写”的误导承诺。

结果：`待验收`

### M03 — 图片原始视觉信息与诚实能力

1. 导入小于 8 MB 的 PNG/JPEG/GIF/WebP 并确认。
2. 在“已授权的本地资料”点击图片的“本地预览”。

预期：

- 标签为“原始视觉来源（只读）”，确认页显示真实宽高。
- 本地预览显示原图，不显示 OCR 摘要或声称 AI 已理解图片。
- 页面持续显示“尚未发送给 AI”；预览说明明确视觉模型尚不可用，未来发送前还需确认上下文范围。
- 关闭预览不会修改源图片。

结果：`待验收`

### M04 — 仅表格/图片也能完成授权

1. 新开一次导入，只选择一张图片或一个 XLSX，不选择文本文件。
2. 点击“确认加入资料”。

预期：

- 确认页正常关闭，来源出现在首页资料清单；不会因为 `documents=[]` 而静默丢失。
- 文本编辑器不会打开伪造的图片/表格文本文件。
- 重新启动应用并恢复该工作区后，来源仍可通过不透明 `sourceId` 列出和本地读取。

结果：`待验收`

### M05 — 上限与恶意输入拒绝

依次尝试导入 257 列 CSV、10001 行 CSV、超过 2 MB 的 CSV，以及超尺寸/错误扩展名图片。

预期：

- 每项在确认前被拒绝，复选框不可用，原因包含具体上限或签名/尺寸错误。
- 不建立来源授权，不显示无法验证的部分解析结果。
- 其他同批合法项仍可独立确认；整批总大小超过 100 MB 时整批不可确认。

结果：`待验收`

### M06 — 取消仍是零授权

1. 拖入一个合法 CSV 和一张合法图片。
2. 在确认页点击取消。

预期：

- 两个文件都不会出现在“已授权的本地资料”。
- 重启后也不会出现；取消不创建新的独立工作区或 `workspace_files` 授权。

结果：`待验收`

### M07 — 内容与路径不越过信任边界

预期：

- 确认页、前端状态和错误提示不显示绝对路径。
- `ImportBatch` 的桌面事件负载只含文件名、大小、能力、状态、原因、警告和随机 ID，不含表格正文或图片字节。
- 只有用户确认后的 `sourceId` 能调用本地读取；任意/过期 ID 返回“来源不存在或未授权”。
- 本阶段没有新的网络、Shell、事件 emit 权限；没有 Provider 请求。

结果：`待验收`

### M09 — 分批追加、重复去重与重启恢复

1. 在同一工作区只加入并确认 `s2-2-basic.csv`，确认首页能看到它。
2. 再发起一次导入，只加入并确认 `s2-2-image.png`。
3. 检查“已授权的本地资料”，然后再次加入同一个 `s2-2-basic.csv`。
4. 完全退出并重新启动应用，恢复该工作区。

预期：

- 第二次确认后，CSV 和图片同时存在；图片不会把 CSV 顶替掉。
- 重复确认同一个 CSV 后只保留一项，不生成重复来源。
- 重启后两种来源仍同时存在，并且仍能本地预览。
- 只有每项明确的“移除”动作可以撤销对应授权；加入另一批资料不会隐式删除。

结果：`验收缺陷已修复并通过自动回归，待用户复验`

### M10 — 单项取消授权且不删除原文件

1. 确保同一工作区至少有一个表格和一张图片，并能正常本地预览。
2. 点击图片右侧“移除”，检查二次确认文案，然后选择“暂不移除”。
3. 再次点击“移除”，选择“取消授权”。
4. 使用资源管理器确认原图片仍存在，再完全退出并重启应用。

预期：

- 确认文案明确说明应用将停止读取，但不会删除设备原文件；已经生成的成果和历史记录不会自动删除。
- “暂不移除”后图片仍在列表中并可预览。
- “取消授权”后只移除该图片；表格等其他来源不受影响，已打开的该来源预览立即关闭。
- 原图片内容和路径没有被修改或删除；重启后图片不会重新出现在已授权列表。
- 已撤销、未知或属于其他工作区的 `sourceId` 不能读取或跨工作区撤销，均返回“来源不存在或未获当前工作区授权”。

结果：`验收缺陷已补齐并通过定向自动回归，待用户复验`
