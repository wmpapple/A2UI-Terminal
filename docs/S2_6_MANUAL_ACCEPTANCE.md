# S2.6 选区助手人工验收

> 状态：**已于 2026-08-27 通过用户人工验收**。验收结论由用户明确回复“`S2.6 验收通过`”确认。

## 1. 验收目标

确认文本或基础表格/代码选区会出现六类动作；解释动作只产生说明，修改动作必须进入统一 Review Request，接受前零写入，拒绝零副作用，接受后可撤销。

## 2. 准备

1. 从当前 S2.6 工作树启动桌面应用，使用虚构或脱敏资料。
2. 准备一个包含两段不同文字的可编辑 Markdown，以及一个 CSV 或纯文本文件。
3. 记录应用 commit、Windows 版本、运行模式和 schema；预期 schema 仍为 `11`。
4. 如使用云端 Provider，不要选取真实密钥、客户资料或个人敏感信息。

## 3. 验收项目

### M01 — 菜单出现与消失

1. 在 Markdown 编辑区选中一段非空文字。
2. 检查编辑器上方出现“选区助手”。
3. 确认存在：润色、缩短、改专业、解释、提取重点、自定义。
4. 切换到其他文件，再返回原文件。

预期：无选区时不显示助手；非空选区显示字符数和六类动作；切换文件后旧选区不会带入。

### M02 — 解释只读

1. 重新选择一段文字并点击“解释”。
2. 检查确认框中的文件、字符数和处理位置。
3. 点击“生成解释”。

预期：说明显示在 AI 助手中；不进入审阅中心；编辑器、磁盘文件、Revision 和 Patch 记录均不变化。

### M03 — 修改必须审阅

1. 选择一段文字并点击“润色”。
2. 确认发送后等待审阅中心出现。
3. 暂不接受，检查编辑器和外部磁盘文件。
4. 点击“全部拒绝”。

预期：Review 来源为选区，候选只针对当前选区；接受前和拒绝后正文均不变，不产生写入版本。

### M04 — 接受与撤销

1. 对同一段重新发起“缩短”或“改专业”。
2. 接受修改并检查正文与版本历史。
3. 点击“撤销上次 AI 修改”。

预期：只修改所选语义块；产生可审计 Revision/Patch/Review；撤销后完整恢复接受前正文。

### M05 — 自定义和提取重点

1. 选择一段文字，在自定义框输入“改成主动语态”，提交并拒绝审阅。
2. 重新选择文字，点击“提取重点”，提交并拒绝审阅。

预期：空自定义要求不会发送；两项修改均进入审阅，不直接改文件；提取重点生成替换候选而不是旁路写入。

### M06 — textarea/表格选区

1. 打开 CSV、纯文本或代码文件。
2. 用鼠标选择一个单元格文本或一段文字，执行“改专业”。

预期：textarea 选区同样显示助手并进入统一 Review；只读导入预览不提供修改入口。

### M07 — 并发与隐私边界

1. 生成修改审阅后，在外部编辑器改变并保存目标文件，再尝试接受。
2. 如 Context Manifest 判断云端选区可能敏感，检查确认框。

预期：外部变化返回冲突且不覆盖新正文；敏感云端内容未勾选明确确认时不能发送；处理位置和字符数始终可见。
