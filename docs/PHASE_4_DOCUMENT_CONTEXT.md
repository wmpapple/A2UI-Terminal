# 阶段 4 补充验收：Word / PDF 上下文

## 已实现

- 真实工作区文件树展示 `.docx` 和 `.pdf`；
- DOCX 正文提取，保留段落并解析 XML 实体；
- PDF 文本层提取；
- 提取内容以只读预览打开，可选择文字或加入会话上下文；
- 原始 Word/PDF 不参与草稿、自动保存或 Patch 写入；
- 扫描 PDF 无文本层时提示需要 OCR；
- 源文档限制 25 MB，提取文本限制 2 MB；
- 路径穿越、符号链接越界和工作区授权规则继续生效。

## 产品验收步骤

1. 执行 `npm run desktop:dev`；
2. 打开一个同时包含 `.docx`、文本型 `.pdf` 和扫描型 `.pdf` 的真实目录；
3. 确认 DOCX/PDF 出现在文件树，打开后显示“只读文档上下文”；
4. 确认正文可以预览、选择，并可通过右键菜单加入当前会话；
5. 确认界面没有保存按钮，原文件内容和修改时间未改变；
6. 确认扫描型 PDF 给出 OCR 提示，而不是显示空白编辑器；
7. 确认超过 25 MB 的文档无法打开，并显示安全提示。

扫描文档 OCR、旧版 `.doc`、复杂表格/图片语义以及 Word/PDF 结构化 Patch 不在本补充范围内。
