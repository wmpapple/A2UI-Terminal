## 4. 安全与隐私

| ID      | 检查               | 预期                                                            |
| ------- | ------------------ | --------------------------------------------------------------- |
| S15-S01 | 观察 Result DTO/UI | 不显示“我的成果”绝对路径；只使用 `result://` 不透明引用         |
| S15-S02 | 检查新建作用域     | 文件只进入应用管理的 `my-results`，不写入当前项目或任意用户路径 |

| S15-S06 | 保存冲突           | 基于 64 位十六进制 SHA-256 基础 Hash 拒绝写入                   |
| S15-S07 | AI 助手外壳        | 不自动发送正文、文件名、路径、Prompt、回复或密钥                |
| S15-S08 | Capability         | 仅新增 7 个 Result 专用命令；无 Shell、任意文件系统或网络权限   |

## 5. 阶段边界

- 已实现：用户主动创建 Markdown/纯文本、托管保存、Result 重开、初始/保存/恢复版本、撤销、查看修改、另存副本、导出入口和双栏外壳。

- “导出”当前必须诚实提示 S2.8；右侧 AI 区当前必须保持不自动发送，不能绕过后续 Context Manifest 和 Review。
