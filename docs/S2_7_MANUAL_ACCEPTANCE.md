# S2.7 成果类型编辑适配手工验收

> 状态：自动验证已通过，等待用户人工验收  
> 基线：`main` / `14243d6`（S2.7 开始基线）

## 1. 验收前准备

1. 完全关闭旧的开发实例，从当前 S2.7 工作树重新启动桌面应用。
2. 使用虚构或脱敏内容；不要把真实敏感资料发送到云端 Provider。
3. 打开“我的成果”，确认顶部入口显示“新建成果”。
4. 本轮可创建 `S2.7 文档测试`、`S2.7 表格测试`、`S2.7 清单测试`、`S2.7 表单测试`、`S2.7 工具测试`，便于完成后自行识别和处理测试数据。

## 2. 人工验收步骤

### M01 — 五类成果新建与格式映射

1. 点击“新建成果”，依次查看成果类型：文档、表格、清单、表单、小工具。
2. 选择文档，确认可选 Markdown 或纯文本；文件名分别要求 `.md/.markdown` 或 `.txt`。
3. 选择表格，确认内部格式固定为 CSV，建议文件名以 `.csv` 结尾。
4. 选择清单、表单、小工具，确认内部格式固定为 JSON，建议文件名以 `.json` 结尾。
5. 分别创建五类成果并打开。

预期：五类成果均可独立创建和重开；成果列表显示真实类型，不全部伪装为文档；同名文件不被覆盖，类型与扩展名不匹配时创建失败并给出错误。

### M02 — 文档编辑、阅读和历史

1. 打开 `S2.7 文档测试`，进入“编辑”，输入标题、段落和 Markdown 列表。
2. 保存后切换到“阅读”，确认内容安全渲染。
3. 再次修改并保存，打开“历史版本”，预览并恢复较早版本。
4. 返回“我的成果”后重新打开该成果。

预期：切换阅读/编辑、路由和重开均不丢已保存内容；每次实际保存形成可查看的 Revision，恢复形成新版本而不删除历史。

### M03 — 表格 CSV 编辑与重开

1. 打开 `S2.7 表格测试`，在原始 CSV 编辑区输入至少三行两列；其中一个单元格包含英文逗号并使用双引号包裹，例如 `"上海,中国"`。
2. 保存并切换到“阅读”。
3. 确认表格预览的行列数及带逗号单元格内容正确。
4. 再次编辑、保存，返回成果列表后重开；再执行“另存副本”。

预期：CSV 引号解析正确，编辑、保存、Revision、重开和副本均使用同一协议；不会执行公式、宏或其他代码。

### M04 — 清单结构化编辑

1. 打开 `S2.7 清单测试`，点击“添加清单项”至少两次。
2. 修改条目文字，勾选其中一项，删除另一项并保存。
3. 切换阅读/编辑并重开成果。

预期：条目文字、完成状态和删除结果均保留；保存后可查看历史；界面不会暴露或执行任意 JSON 代码。

### M05 — 表单结构化编辑

1. 打开 `S2.7 表单测试`，添加多个字段。
2. 分别设置文本、数字、日期、复选框类型，并切换“必填”。
3. 保存、切换阅读/编辑并重开成果。

预期：字段名称、类型、必填状态均保留；“必填”复选框与文字在同一行垂直居中，不出现勾选图标漂移到卡片上方；重复或非法内部标识不能绕过 Rust 校验写入。

### M06 — 小工具配置与 A2UI 快照边界

1. 打开手工创建的 `S2.7 工具测试`，添加或修改安全键值配置并保存、重开。
2. 如已有由可信 A2UI Surface 生成的小工具成果，从“我的成果”打开它。
3. 在原 A2UI Surface 中触发一个允许的状态动作，再重新打开对应成果快照。

预期：普通小工具只编辑受控配置；A2UI 来源成果显示“已验证的 A2UI 工具快照”提示且为只读，其控件状态由 A2UI Action 自动保存并在成果快照中更新；任何脚本、HTML、宏或动态代码都不会执行。若当前没有 A2UI Surface，可记录第 2—3 步为“无测试前置”，不影响其余五类 adapter 验收。

### M07 — 共享保存、冲突与状态保持

1. 任选五类成果，修改但尚未保存时在“阅读/编辑”间切换，再保存。
2. 保存后查看“查看修改”“撤销”“历史版本”和“另存副本”。
3. 可选冲突验证：在应用外修改对应托管文件后，尝试保存旧编辑内容。

预期：视图切换不丢当前编辑状态；各类型共享一致的保存状态和版本工具；外部变化导致 Hash 冲突并停止，不静默覆盖磁盘内容；既有 Review/历史信息不因切换 adapter 丢失。

### M08 — 阶段边界

1. 点击“导出”。
2. 检查是否出现真实 DOCX/PDF/XLSX 写入、系统保存对话框或“导出成功”假提示。

预期：只明确提示真实导出属于 S2.8；本阶段没有 DOCX/PDF/XLSX 无损回写，没有任意路径写入，没有新增 Provider 上传、脚本执行或遥测。
