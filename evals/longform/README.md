# 长文质量回归

`cases.json` 固定两份三章任务和门槛，资料全部虚构。评测通过真实产品规划、确认、Provider、逐章接受和成果合成流程。工程执行成功与模型质量达标分别记录；未达标模型不作为本阶段推荐模型。

自动门槛检查已知事实保留、带引用章节比例、未知引用键、明显错误审批表述、最低全文长度和重复段落。`manual-review.json` 另记录事实推断、引用是否支持断言、章节目标和术语等语义检查，由代理检查原文，不替代用户产品验收。自动字符串命中不能证明全部事实准确，单次小样本不能承诺稳定成功率。

运行方法、固定模型 revision、环境和报告路径见 [M6 执行记录](../../docs/V2.X/M6_EXECUTION.md)。修改模型、Prompt 或关键上下文后应重新运行；不得为使当前输出通过而降低原门槛。评测工具不安装进桌面产品，也不读取用户 API Key。

`eval:longform` 返回成功表示六章流程已执行；`eval:longform:score` 未达标时返回非零。`audit:longform` 校验工程证据，并单独输出 `modelQualifiedOnFixedCases`，不能将 `engineeringPassed` 用作模型推荐依据。
